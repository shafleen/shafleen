# Hi, I’m Shafleen 👋

I build thoughtful, self hosted software for people who work with data and operational systems.

I enjoy turning complicated workflows into tools that feel clear, practical, and pleasant to use. I care about privacy, simplicity, and giving people control over their own systems and data.

My latest open source project is [**SQL Canvas**](https://github.com/shafleen/SQL-Canvas), a visual first workspace for MySQL and MariaDB. It brings data exploration, schema mapping, SQL queries, imports, exports, and database administration together in one modern interface.

I am always learning, improving, and building software that solves real problems.
